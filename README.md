# 🍳 Smart Recipe

Smart Recipe is an ingredient-based recipe recommendation system that suggests recipes using the ingredients available at home.

### Features

* 🥕 Search recipes using available ingredients
* 🔍 Find suitable recipes
* 🔄 Suggest substitutes for missing ingredients
* ⭐ Recommend the most relevant recipes
* 📚 Recipe database

## Uses

* Helps users decide what to cook with available ingredients.
* Reduces food wastage.
* Suggests alternatives for missing ingredients.
* Makes meal planning easier.
* Reduces unnecessary grocery trips.
## Advantages

* Reduces food wastage.
* Saves time in deciding what to cook.
* Reduces unnecessary grocery trips.
* Helps use ingredients already available at home.
* Provides alternatives for missing ingredients.
* Makes meal planning easier.
